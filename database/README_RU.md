# База проверенных SHA-256 сигнатур

`known_hashes.json` содержит только точные SHA-256 совпадения. SentinelXT учитывает
запись как подтверждённую только при `"verified": true`.

Пример структуры записи:

```json
{
  "sha256": "64-символьный-нижний-регистр-хеш",
  "label": "Название точно идентифицированного артефакта",
  "family": "minecraft-cheat-client",
  "source": "URL или описание независимого источника проверки",
  "verified": true
}
```

Не добавляйте хеш по одному имени файла или неподтверждённому сообщению. Хеш должен
быть получен из конкретного образца и независимо проверен. Пустая база означает,
что точных хеш-совпадений пока нет; это не означает, что файл безопасен.
